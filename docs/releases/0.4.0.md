## New and improved

(Written for users when the items are finished; the Ollama block so far:)

- **Your own Ollama for local chat.** Settings > Ollama (local chat) shows whether Ollama answers and lets you point Sachivji at an Ollama on another machine. "Ollama (local)" disappears from the model list while Ollama is not running and comes back by itself.
- **Fallback when Ollama is down (optional).** Pick a hosted model; with your tick box it answers a message when Ollama is not running, and the chat tells you the conversation was sent to that provider.
- **Search index protection.** If the embedding model is reinstalled or updated, you are told the index needs a rebuild instead of search quietly getting worse.

## Fixed

- Ollama Cloud models such as `gemma4:cloud` are no longer shown as free ($0) in the usage meter (#168).
- The bundled Ollama no longer takes Ollama's standard port 11434, so it cannot get in the way of your own Ollama (#214).

## Known limits

- Hosted fallback is for a down Ollama only; other providers' outages, choosing a model by task, and fallback chains are 0.5.0 work (`docs/auto_model_selection.md`).
- The embedding model is not pinned by digest (Ollama pulls by name and tag); a change is detected, not prevented (#224).
